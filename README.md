# 房东宝 FangDongBao PWA

家庭房屋收租管理渐进式网络应用（PWA）——给"家里每人一栋楼"的家庭用。

## 功能一览

- 🏠 **多房东**：每位家庭成员一个账号，各记各的楼；管理员可查看/编辑全家数据
- 📷 **抄表拍照**：拍电表/水表照片存档，本地 OCR 辅助识别读数（人工确认），自动算费用量
- 🧮 **自动算费**：房租 + 电费（按表/包干/全包）+ 水费（同）+ 网费 + 任意杂费/减免，每一项都可手改
- 💰 **分次收款**：交一部分记一部分，自动算还差多少；逾期账单醒目标红
- ⏰ **收租提醒**：每人收租日不同；收租日/逾期手机弹窗推送（免费方案）
- 📊 **年度统计**：月度实收、科目构成、收缴率、楼栋汇总，一键导出 CSV
- 📴 **离线可用**：本地优先存储（IndexedDB），断网也能抄表记账，联网后自动云同步
- 💾 **数据自主**：随时导出完整备份（JSON），导入恢复——数据永不锁死

## 成本

**0 元**。托管用 GitHub Pages，云同步与推送用 Supabase 免费额度（家庭用量远低于限额，无需绑卡），OCR 本地运行。详见 [docs/使用指南.md](docs/使用指南.md)。

## 技术栈

Vue 3 + Vant 4 + Pinia + Dexie.js (IndexedDB) + Supabase (Postgres RLS + Edge Functions + pg_cron) + Tesseract.js + ECharts + vite-plugin-pwa。部署：GitHub Actions → GitHub Pages。
