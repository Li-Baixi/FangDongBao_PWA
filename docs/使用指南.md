## 一、这个应用是什么？要花多少钱？

房东宝是一个装在手机上的收租记账应用（网页做的，但装到桌面后用起来和普通 App 一样）。
拍电表水表、自动算钱、分次收款、逾期提醒、年度统计，全都齐了。

**钱的事，说清楚：**

| 东西 | 用的是 | 花钱吗 |
|---|---|---|
| 应用代码 | 自己的 GitHub 仓库 | 免费 |
| 网站托管 | GitHub Pages | 免费 |
| 云同步/账号 | Supabase 免费版 | 免费（不绑卡，日常用量用不到限额的 1%） |
| 收租提醒推送 | 浏览器推送 + Supabase 定时任务 | 免费 |

唯一要知道的事：**Supabase 免费项目如果连续 7 天没有任何访问会被暂停**。
我们的收租提醒每天自动跑一次，等于每天都会访问它，所以一般不会发生；
万一真暂停了，登录 supabase.com 点一下 "Restore" 就恢复，数据不会丢。

## 二、先在自己电脑上看效果（可选）

想先看看长什么样、试试功能，再决定配置云同步？可以：

1. 打开命令行（按键盘 `Win + R`，输入 `cmd` 回车）
2. 输入下面这行，回车（切换到项目文件夹）：
   ```
   cd /d E:\fangdongbao_pwa
   ```
3. 输入下面这行，回车（启动）：
   ```
   npm run dev
   ```
4. 等它输出一行类似 `Local: http://localhost:5173/...` 的地址，
   按住 Ctrl 点击或复制到浏览器打开
5. 这时是**本机单机模式**：建一个档案就能开始记数据
6. 看完想关掉：回到命令行窗口按 `Ctrl + C`，再按 Y 回车

> 注意：没配置云同步时，数据只存在这台电脑的这个浏览器里。
> 正式使用请继续往下做第三步。

## 三、配置云同步——让多个用户手机数据互通（做一次）

我们用 Supabase 做云端数据库。注册到配置完大约 15 分钟。

### 1. 注册 Supabase（免费）

1. 浏览器打开 **https://supabase.com**
2. 点右上角 **Start your project** → 选 **Continue with GitHub**（直接用你的 GitHub 账号登录，不用另注册）
3. 授权完成后进入控制台

### 2. 创建项目

1. 点 **New project**
2. 填写：
   - **Name**：`fangdongbao`（随便起，认识就行）
   - **Database Password**：点 **Generate a password**，**把生成的密码复制存好**（存到手机备忘录也行，丢了比较麻烦）
   - **Region**：选 **Southeast Asia (Singapore)**（离中国最近）
3. 点 **Create new project**，等 1~2 分钟建好

### 3. 建数据库表（复制粘贴一段代码）

1. 左侧栏点 **SQL Editor**（图标像个终端）
2. 点 **New query**
3. 打开本项目的文件 `supabase/migrations/0001_init.sql`，
  用记事本打开，**全选复制**，粘贴到 SQL Editor 的输入框里
4. 点右下角 **Run**（或按 Ctrl+Enter）
5. 显示 `Success. No rows returned` 就成功了

### 4. 关掉注册时的邮箱验证（用户注册省事）

1. 左侧栏点 **Authentication** → **Sign Up / Providers**（旧版叫 Providers）
2. 找到 **Email**，把 **Confirm email** 开关**关掉**
3. 这样用户注册完立刻能登录，不用去邮箱点验证链接

### 5. 拿两串钥匙，填到项目里

1. 左侧栏点齿轮 **Project Settings** → **API**
2. 找到两样东西：
   - **Project URL**（形如 `https://abcd1234.supabase.co`）
   - **anon public** 密钥（很长的一串字母数字）
3. 回到项目文件夹 `E:\fangdongbao_pwa`：
   - 复制 `.env.example` 文件，把副本改名为 `.env`（如果看不到 .example 后缀，
     让 Claude 帮你建）
   - 用记事本打开 `.env`，把两串值填进去，保存：
     ```
     VITE_SUPABASE_URL=https://abcd1234.supabase.co
     VITE_SUPABASE_ANON_KEY=eyJhbGciOi...很长一串
     VITE_VAPID_PUBLIC_KEY=（这行先空着，第五步再填）
     ```
   - anon 密钥是"公开钥匙"，设计上就可以放在前端，**但 service_role 密钥绝对不能放前端**。

> 做完这步，下次 `npm run dev` 启动就是云模式（登录页变成邮箱登录）。
> **第一个注册的人自动成为管理员**——请你自己先注册，再让其他用户注册。

## 四、发布到网上——手机才能安装（做一次）

网站要放在公网上，手机才能安装成应用。用 GitHub Pages（免费）。

### 1. 把代码推送到 GitHub

如果 Claude 还没帮你推送，在命令行里（项目文件夹下）执行：
```
git add -A
git commit -m "房东宝初始版本"
git push -u origin main
```
第一次 push 会弹出 GitHub 登录窗口，用浏览器登录授权即可。

### 2. 在仓库里放钥匙（Secrets）

1. 打开 **https://github.com/Li-Baixi/FangDongBao_PWA**
2. 点 **Settings** → 左侧 **Secrets and variables** → **Actions** → **New repository secret**
3. 添加三个（名字必须一字不差，值就是 `.env` 里那三个）：
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
   - `VITE_VAPID_PUBLIC_KEY`（第五步生成后再来加也行）

### 3. 打开 Pages

1. 仓库页 **Settings** → 左侧 **Pages**
2. **Build and deployment** 下面 Source 选 **GitHub Actions**
3. 保存。之后每次 `git push`，GitHub 会自动构建发布（Actions 页能看到进度，1~2 分钟）

### 4. 拿到安装地址

发布成功后，访问：
**https://li-baixi.github.io/FangDongBao_PWA/**

这就是大家安装应用用的网址（建议分享给其他用户）。

## 五、开启收租提醒弹窗（做一次）

原理：Supabase 每分钟看一眼（很轻量的检查），到了**每位用户自己选的提醒时间**（可精确到分钟，
默认早上 9:00，在应用「我的 → 提醒时间」修改）才检查谁该收租了，给手机发推送。全部在免费额度内。

### 1. 生成推送密钥

命令行（项目文件夹下）：
```
npm run gen:vapid
```
会打印出**公钥**和**私钥**两串字符。

### 2. 分发密钥（重要，别弄反）

- **公钥**放三个地方：
  1. `.env` 文件的 `VITE_VAPID_PUBLIC_KEY=`
  2. GitHub 仓库 Secrets 里加 `VITE_VAPID_PUBLIC_KEY`
  3. 下面第 3 步的 Supabase secrets
- **私钥**只放 Supabase secrets（谁拿到私钥谁就能给你的手机发通知，别放别处）

### 3. 安装 Supabase 命令行并部署提醒函数

1. 按 **Win + R** 输入 `cmd` 回车，执行（装 Supabase CLI，一次性）：
   ```
   npm install -g supabase
   ```
2. 登录（会打开浏览器授权）：
   ```
   supabase login
   ```
3. 关联项目（在项目文件夹下执行；`项目ref` 见 Supabase 网页 Settings → General 的 Reference ID）：
   ```
   supabase link --project-ref 你的项目ref
   ```
4. 设置推送密钥：
   ```
   supabase secrets set VAPID_PUBLIC_KEY=公钥粘贴这里 VAPID_PRIVATE_KEY=私钥粘贴这里 PUSH_NOTIFY_MAILTO=mailto:你的邮箱@xx.com
   ```
5. 部署提醒函数：
   ```
   supabase functions deploy rent-reminder
   ```

### 4. 设置每天自动运行

1. 打开 `supabase/migrations/0002_cron.sql`，用记事本编辑，替换两处：
   - `PROJECT_REF` → 你的项目 ref（Settings → General 里那串）
   - `SERVICE_ROLE_KEY` → Settings → API 里的 `service_role` 密钥
     （这串是管理员权限密钥，只贴在这里，**永远不要**放进 `.env` 或 GitHub）
2. 全选复制，粘贴到 Supabase 的 **SQL Editor** → **Run**

### 5. 测试一次（可选但建议）

命令行：
```
curl -X POST "https://项目ref.supabase.co/functions/v1/rent-reminder" -H "Authorization: Bearer service_role密钥"
```
返回 `{"ok":true,...}` 就说明部署成功。
（没人在手机上开过推送的话 `sent` 是 0，正常——要先做第六步。）

## 六、手机安装（每位用户各自做）

### 安卓手机

1. 用 **Chrome 浏览器**打开 `https://li-baixi.github.io/FangDongBao_PWA/`
2. 没账号：登录页点"注册一个"（邮箱 + 密码 + 称呼），注册完直接登录
3. 点浏览器菜单「⋮」→「**添加到主屏幕**」（有的叫"安装应用"）
4. 桌面出现"房东宝"图标，以后从桌面打开
5. 开提醒：应用里「我的」→「**收租提醒推送**」开关打开 → 允许；提醒时间在「提醒时间」里自己选

### iPhone（需 iOS 16.4 以上）

1. 用 **Safari**（不是微信！微信里打开装不了）打开上面网址
2. 注册/登录同上
3. 点 Safari 底部「**分享**」按钮（方框带向上箭头）→「**添加到主屏幕**」→ 添加
4. 从**桌面图标**打开应用（必须，微信/Safari 里打开没有推送资格）
5. 「我的」→「收租提醒推送」开关打开 → 允许；再去 **iPhone 设置 → 通知 → 房东宝** 允许通知

应用内也有这份说明：「我的」→「怎么装到手机桌面」。

## 七、日常使用

### 每月收租（核心，就 4 步）

1. 打开房东宝，首页「**今天该收租**」里点「去收租」（或点底部大按钮）
2. 拍电表 → 看表输本次读数（会自动带上上次读数、算好差值和钱）；
   读数直接关系算钱，请看清表盘再输入
3. 拍水表 → 同上
4. 核对账单（房租、水、电都是自动算的，可点任意一项改金额，可加杂费/减免）→
   选择「这次收齐 / 部分收款 / 暂不收」→ 完成 ✅

### 常见状况怎么办

| 状况 | 做法 |
|---|---|
| 租客分几次交租 | 收一次记一次：账单页选「部分收款」，输入本次金额；系统自动算还差多少 |
| 交租延误 | 不用管，过了收租日自动标红"逾期 N 天"，首页和推送都会提醒你 |
| 抄表时忘了拍/拍糊了 | 直接手输读数就行，照片不是必填；下次补拍也行 |
| 表清零了/换新表 | 本次读数比上次小会显示红色警告，核对无误直接继续即可 |
| 月份搞错了 | 收租向导里「收租月份」可以改，选错月补录上月也行 |
| 租客退租 | 租客详情 →「退租」。人不在列表里了，但历史账单都在 |
| 手滑记错金额 | 租客详情 → 展开那期账单 →「补记/修改」重走一遍向导就能改 |
| 有杂费（卫生费、换锁…） | 账单确认页「加杂费」；给租客优惠用「记减免」（自动算负数） |

### 管理员（你）的特权

- 首页右上角下拉：**我的 / 全部 / 某位用户**，随时切换查看谁的数据
- 「我的」页连点版本号 5 次出现「平台管理」入口：给用户改名、设置/取消管理员
- 统计页：年份随便选，收入构成、收缴率、各楼对比，还能「导出表格」给会计/自己留档

### 数据安全（重要习惯）

**每月点一次：「我的」→「导出备份文件」**（勾上"包含拍照原图"），
把下载的 JSON 文件存到电脑或网盘。这样就算手机丢了、Supabase 哪天政策变了，
数据也能完整恢复（「从备份恢复/导入」）。

## 八、常见问题

**Q：换了新手机，数据怎么办？**
装好应用、登录同一账号，数据自动从云端同步下来。照片原图不云同步（省空间），
想带走就用旧手机导出备份 → 新手机导入。

**Q：忘了登录密码？**
登录页目前没有自助改密（内部小范围使用）。管理员也改不了别人的密码（这是安全设计）。
最简单的解决：Supabase 控制台 → Authentication → Users → 找到那个人 → 发送密码重置，
或者直接删掉这个用户让他重新注册（数据还在，重新注册后要重新关联，找 Claude 帮忙处理）。

**Q：家里没网/楼里信号差，能记账吗？**
能。所有操作先存在手机本地，有网了自动同步（「我的」页能看到"待同步 N 条"）。

**Q：Supabase 项目被暂停了（7 天没人访问）？**
登录 supabase.com → 项目页面点 **Restore project**，等几分钟恢复，数据无损。
配好了每日提醒就不会发生这事。

**Q：为什么没有"自动识别"读数？**
读数直接关系算钱，机器可能认错数字，所以只保留拍照存证，读数一律人工看表填写。
拍照时正对表盘、离近点、避免反光，事后翻查更清楚。

**Q：微信里打开网址能用吗？**
能用，但**装不了应用也收不到推送**。一定用 Chrome（安卓）/ Safari（iPhone）打开再添加到主屏幕。

**Q：想改收租日、房租涨价了？**
租客列表 → 点租客 → 「编辑」。改完下期账单按新规则算，历史账单不变。

**Q：这个软件安全吗？家里人之外的人能看到吗？**
数据库有行级权限：每人只能读写自己的数据，管理员才能看全部，未登录的陌生人什么都拿不到。
代码公开在你自己的 GitHub 仓库里，随时可以审查。
